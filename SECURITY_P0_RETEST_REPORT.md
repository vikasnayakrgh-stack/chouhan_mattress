## 4. Payment Security — Pre-Integration Requirements

Since live payment gateway integration (Razorpay / Stripe) is not yet active in code, payment flow security is marked as **`PAYMENT SECURITY — NOT YET TESTABLE`**.

Before activating live payment processing, the following controls MUST be implemented:
1. **Server-Generated Payment Orders**: Razorpay/Stripe order creation MUST use the `finalPayableAmount` generated by `/api/checkout/create-order`.
2. **Webhook Signature Verification**: All webhook endpoints (`/api/webhooks/razorpay`) MUST verify HMAC signatures (`X-Razorpay-Signature`) using secret tokens before updating order status.
3. **Idempotency & Replay Protection**: Webhook handlers MUST verify duplicate event IDs in PostgreSQL before processing order fulfillment.
